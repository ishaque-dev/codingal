Why Use Semantic Tags?

Semantic tags give meaning to our web pages. They tell the browser and screen readers exactly what type of content is inside them.

Popular Semantic Tags

Some of the most common semantic tags include header, footer, nav, section, and article. Using these helps with SEO (Search Engine Optimization)!

Fun Fact

Before semantic HTML5 tags were introduced, developers had to rely on div tags for everything!
